This wiki is built with [juicer](https://github.com/edadma/juicer) using the `juicerwiki` theme. Notes live as flat markdown files under `content/`; every internal link automatically populates the linked note's backlinks panel.

The closest cousin of this layout is the original [Zettelkasten](/zettelkasten/) method as practiced by Niklas Luhmann. The original was a paper card index; this is the digital equivalent without the index cards.
