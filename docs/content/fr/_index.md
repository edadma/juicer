## Pourquoi Juicer ?

Juicer s'inspire de Hugo : une arborescence de contenu markdown, une arborescence de gabarits HTML, des conventions qui les relient et une interface en ligne de commande qui en fait un site statique. Il fait ce dont la plupart des auteurs de documentation et de blogues ont réellement besoin — et guère plus.

```bash
sbt 'juicerJVM/run serve -s docs -L'
```

Cette seule commande construit la documentation que vous lisez en ce moment, surveille les changements et recharge vos onglets de navigateur. Essayez-la.
